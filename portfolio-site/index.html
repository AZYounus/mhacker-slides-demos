MHACKERS: INTRO TO WEB DEV

The intro to web development team runs every semester. We go through HTML (putting content on a webpage), CSS (making content look pretty), JavaScript (adding interactivity with the webpage), and React (javascript library to reduce and reuse code by thinking of elements of your page as components). We do not assume any experience with programming or writing web pages at all. Honestly, you could have never touched a computer in your life and you would be a good fit here. The idea is to get used to writing webpages the painful way (through HTMl, CSS, and JavaScript) and foreshadow about looking at websites through the idea of layers or components so when we get to using React, it will be pretty intuitive functionally and you will understand the need to worship the creators of React and other frontend libraries. Implementing and syntax will take some time though and that's to be expected.

WHAT IS WEB DEVELOPMENT?

Web development is everything that goes into building and maintaing a website. Web development is composed of two main fields:

  1. Front end
  2. Back end

The front end (also known as client side) is the user interface. This is the content on the page (HTML), the styling of the page content (CSS), and the ability to interact with the elements on the page (JavaScript) whether that's through clicking buttons, hovering over items, or other such interactions.
The back end side of things (also known as server side) is how the website actually runs. This includes how our browser knows what files to render based on the links we type into our search bar (browser communicates with server in what's known as a request-response cycle), interacting with a database, API or Application Programming Interfaces (software that describes how two computers usually a client and a server interface with each other using requests and responses), and any other infrastructure.

WHAT WE DO

Web development beginner consists of thirty minutes of content through lecture style followed by challenge of the day. The challenges compound throughout the weeks so by the end of the semester you will have a finished website. You are given about thirty minutes to complete the challege, after which I walk through the solution and explain how I would have approached the problem. Your approach may have been different and that's perfectly valid. My solutions are posted with my Github. As this is my first semester teaching web beginner, the pacing and demos may change especially depending on feedback.

WHAT SHOULD I KNOW BEFORE ARRIVING?

You don't need to know anything when you join this team. We will teach you everything although there is definitely a learning curve at the beginning because there are many terms thrown around and tags. With practice, you will get better and more confident. Also Google things. You probably won't ever know everything that these languages and frameworks can offer you and that's normal. Just like with programming languages, online forums such as Stack Overflow, Free Code Camp, Reddit, etc as well as websites like MDN (Mozilla Doc Notes) Web Docs, W3Schools, HTML.com, web.dev, etc.
